日常写作流程

以后每次写文章，就三步：
bash

cd ~/Blog
hexo new "文章标题"

编辑 source/_posts/文章标题.md，写完保存，然后：
bash

git add .
git commit -m "post: 文章标题"
git push

推送后 Actions 自动构建，一两分钟后刷新 https://robetthjf.github.io/ 就能看到新文章。不需要手动 hexo generate，那是本地预览用的。
本地预览

想先看看效果再推：
bash

hexo clean && hexo server

打开 http://localhost:4000 预览，满意了再 git push。
